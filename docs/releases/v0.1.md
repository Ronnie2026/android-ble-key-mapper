首个公开版本。

- 学习外接蓝牙键盘按键，自定义短按与长按映射。
- 创建命名动作，选择单个或多个 APP，支持搜索与图标展示。
- 提供简洁的快捷键、动作、设置界面，以及可选 Windows BLE 测试按钮。
- 当前后台执行实现需要 root，实体第三方键盘的兼容性仍需按型号验证。

安装附件中的 APK；SHA256SUMS.txt 用于核对下载文件。沿用原签名及应用 ID，内部 versionCode 从 3 升到 4，支持覆盖此前本地测试版并保留配置。公开版本号从 0.1 开始。

已验证 Android 11 一加实机及模拟器上的既有功能；不保证任意 Android 版本或实体键盘兼容。打开 DiPlay、豆包等目标 APP，不等同于自动开始投屏或语音会话。
